🚀 DÉMARRER EN 3 ÉTAPES
════════════════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 1 : Ouvrir un terminal (CMD ou PowerShell)                            │
└──────────────────────────────────────────────────────────────────────────────┘

Appuyez sur Windows + R, tapez "cmd" et appuyez sur Entrée


┌──────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 2 : Naviguer vers le dossier du projet                                │
└──────────────────────────────────────────────────────────────────────────────┘

Tapez cette commande et appuyez sur Entrée :

    cd C:\Stagilog\stagilog


┌──────────────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 3 : Démarrer le serveur Laravel                                       │
└──────────────────────────────────────────────────────────────────────────────┘

Tapez cette commande et appuyez sur Entrée :

    php artisan serve


Vous devriez voir :

    Laravel development server started: http://127.0.0.1:8000
    [Ctrl+C to quit]

✅ PARFAIT ! Le serveur est démarré !

PROBLÈME : "Connection refused" ou "Unable to connect"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ Solution : Le serveur n'est pas démarré

   1. Ouvrir un terminal
   2. cd C:\Stagilog\stagilog
   3. php artisan serve


PROBLÈME : Page blanche ou erreur 500
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ Solution : Vider tous les caches

   1. Dans le terminal où le serveur tourne, appuyez sur CTRL+C pour l'arrêter
   2. Tapez : php artisan optimize:clear
   3. Tapez : php artisan serve
   4. Rechargez la page dans votre navigateur


PROBLÈME : Erreur 404 Not Found
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ Solution : Vérifier l'URL

   Correct   : http://localhost:8000
   Incorrect : http://localhost (sans :8000)


PROBLÈME : Images ne s'affichent pas
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ Solution : Les images sont dans le bon dossier

   Vérifiez que ces fichiers existent :
   - C:\Stagilog\stagilog\public\images\logo-tfg.png
   - C:\Stagilog\stagilog\public\images\bg-login.jpg
