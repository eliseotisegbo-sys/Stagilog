═══════════════════════════════════════════════════════════════
🎯 FONCTIONNALITÉS PRINCIPALES
═══════════════════════════════════════════════════════════════

1. POUR UNE ÉCOLE :
   • Créer un dossier et ajouter tous les étudiants en une fois
   • Consulter le statut de tous ses dossiers
   • Voir les rapports déposés par les étudiants

2. POUR UN ÉTUDIANT :
   • Rechercher son dossier par nom + prénom
   • Voir le statut de son dossier (en attente / validé / refusé)
   • Déposer son rapport (uniquement si le dossier est validé)

3. POUR L'ADMINISTRATION :
   • Voir tous les dossiers avec statistiques
   • Valider les dossiers (permet le dépôt de rapports)
   • Refuser les dossiers (supprime le dossier + étudiants)

═══════════════════════════════════════════════════════════════
🔐 RÈGLES IMPORTANTES
═══════════════════════════════════════════════════════════════

✅ DÉPÔT DE RAPPORT :
   • Si dossier "en attente" → BLOQUÉ
   • Si dossier "refusé" → BLOQUÉ
   • Si dossier "validé" → AUTORISÉ

✅ REFUS D'UN DOSSIER :
   • Supprime automatiquement le dossier
   • Supprime tous les étudiants liés

✅ DEUX MODES DE DÉPÔT :
   • Par école : rapport commun pour plusieurs étudiants
   • Par étudiant : rapport individuel
