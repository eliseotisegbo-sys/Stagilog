🔧 POUR ENVOYER DE VRAIS EMAILS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Vous avez 3 options :

Option 1 : MAILTRAP (Recommandé pour tests)
├─ Gratuit
├─ Parfait pour le développement
├─ Les emails sont interceptés (pas envoyés vraiment)
└─ Site : https://mailtrap.io

Option 2 : GMAIL (Pour production)
├─ Gratuit (500 emails/jour)
├─ Emails réellement envoyés
├─ Nécessite un compte Gmail
└─ Nécessite un "App Password"

Option 3 : SERVEUR SMTP PROFESSIONNEL
├─ Pour domaine personnalisé (@tfg-sarl.com)
├─ Nécessite un hébergeur email
└─ Configuration SMTP fournie par l'hébergeur

📋 INFORMATIONS NÉCESSAIRES POUR CONFIGURER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Pour configurer l'envoi d'emails, vous aurez besoin de :

1. MAIL_HOST      : Serveur SMTP (ex: smtp.gmail.com)
2. MAIL_PORT      : Port SMTP (587 pour TLS, 465 pour SSL)
3. MAIL_USERNAME  : Votre adresse email complète
4. MAIL_PASSWORD  : Mot de passe ou App Password
5. MAIL_ENCRYPTION: Type de chiffrement (tls ou ssl)

Ces informations doivent être ajoutées dans le fichier :
C:\Stagilog\stagilog\.env
